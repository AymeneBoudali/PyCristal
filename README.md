# PyCristal `v0.1.0`

**Give your Python terminal a little glow. ✨**

PyCristal is a lightweight, dependency-free Python library for beautiful terminal messages.

## Installation

Coming soon! 💚

## Quick start

```python
import pycristal as pc

pc.success("Done!")
pc.info("Application started!")
pc.warning("Be careful!")
pc.error("Something went wrong!")
```

## Features

- Colored terminal messages
- Simple and beginner-friendly
- No external dependencies
